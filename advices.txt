• Осветление:           rgba(255, 255, 255, 0.3)
• Градиент сверху вниз: linear-gradient(to top, #111, transparent)
• Радиальный градиент:  radial-gradient(circle, rgba(0,0,0,0.6), transparent)

TNTSearch — краткая инструкция
1. Установка
bash

composer require teamtnt/laravel-scout-tntsearch-driver
php artisan vendor:publish --provider="Laravel\Scout\ScoutServiceProvider"
2. Настройка
В .env:

SCOUT_DRIVER=tntsearch
В моделях (Chapter, Book, Article):

php

use Laravel\Scout\Searchable;

class Chapter extends Model
{
    use Searchable;

    public function toSearchableArray(): array
    {
        return [
            'title' => $this->title ?? '',
            'content_html' => substr(strip_tags($this->content_html ?? ''), 0, 10000),
        ];
    }
}
3. Импорт (выполнять один раз и после крупных обновлений)
bash

php -d memory_limit=1G artisan scout:import "App\Models\Chapter" --chunk=50
php -d memory_limit=1G artisan scout:import "App\Models\Book" --chunk=50
php -d memory_limit=1G artisan scout:import "App\Models\Article" --chunk=50
Индексы сохраняются в storage/tntsearch/.

4. Поиск

Chapter::search('запрос')->get();
5. На продакшене
Убедись, что storage/tntsearch/ доступна для записи.
